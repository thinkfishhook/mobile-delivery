# Security policy

## Supported versions

Security fixes target the latest released `v1` minor version. Use its latest patch
release; older minor versions are not supported.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/thinkfishhook/mobile-delivery/security/advisories/new)
from this repository's **Security → Report a vulnerability** page. Keep suspected
vulnerabilities private while maintainers investigate and coordinate a fix. Private
reporting must be enabled by the repository owner before that form is available.

Include the affected revision or release, a minimal reproduction, the expected behavior,
and the potential impact. Use synthetic credentials and redact logs. Do not include signing
certificates, private keys, tokens, provisioning profiles, or customer data. Do not open a
public issue containing vulnerability details or credentials.

If a credential has been exposed, revoke or rotate it through its issuing service; deleting
it from a report or Git history does not revoke it.
